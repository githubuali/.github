# githubuali/.github

Formularios de issues y plantilla de PR por defecto para todos los repos de la organización que no tengan los suyos.

- **Formularios** (`.github/ISSUE_TEMPLATE/`): Feature, Tarea, BAU, Bug y Test case. Cada uno pone el tipo, las etiquetas y agrega el issue a UALI Tareas.
- **Plantilla de PR** (`.github/pull_request_template.md`): `Closes #n` y `Refs githubuali/<repo>#n`.

La fuente es `templates/github/` en `githubuali/delivery-insights`: los cambios se revisan ahí y se copian acá.
